# dsh-rss-news-daily

**每天花更少时间，掌握值得关注的新闻。**

`dsh-rss-news-daily` 是一款面向 dsh 用户的 RSS 新闻阅读与精选插件。它会按计划收集你关注的信息源，用 AI 整理新闻重点，并提供一个独立的阅读面板，方便你查看每日精选和全部新闻。

## 它能帮你做什么

- **快速了解当天重点**：查看 AI 整理的日报，也可以浏览按时段更新的快报。
- **阅读完整新闻列表**：搜索新闻、按分类筛选、只看未读，或按发布时间和抓取时间排序。
- **选择自己关注的信息源**：从 53 个内置订阅源开始，也可以添加自己的 RSS/Atom 地址，或导入 OPML 订阅清单。
- **按习惯调整内容**：通过喜欢或不感兴趣的反馈，逐步调整后续推荐；还可以设置抓取和日报生成时间。
- **阅读外文新闻**：需要时使用 AI 翻译，并查看翻译进度。
- **掌握后台进度**：查看抓取和翻译状态；进行中的任务可以取消。

插件提供独立的阅读面板，不会自动把新闻内容放进聊天对话。新闻条目保存在本机；使用 AI 总结、评分或翻译时，相关新闻内容会发送给你在 dsh 中配置的模型服务。

## 开始使用

1. 在 dsh 的插件管理中搜索并安装 `dsh-rss-news-daily`。
2. 确认 dsh 已配置可用的 AI 模型，以使用新闻精选、总结和翻译功能。
3. 打开插件，选择关注的订阅分类，并按需调整抓取和日报时间。
4. 前往「全部新闻」阅读资讯，或在「今日精选」查看日报与快报。

也可以在终端中安装：

```sh
dsh plugin --profile web add dsh-rss-news-daily
```
