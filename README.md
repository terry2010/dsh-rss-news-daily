# dsh-rss-news-daily

Daily RSS news digest plugin for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (`dsh`).

This package name is reserved; the first release is in development.

Planned features:

- Daily briefing: an overall news summary plus top-N important items (count configurable)
- Custom RSS/Atom sources (manage in GUI, OPML import/export)
- Sidebar reader: browse all feeds, filter by category, read/unread, day-by-day archive
- Preference tuning in natural language ("more AI, less crypto")
- No context cost: nothing is injected into the conversation
