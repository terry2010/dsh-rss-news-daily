# dsh-rss-news-daily

**不用在多个网站之间来回切换，也能及时掌握自己关心的新闻。**

[![npm version](https://img.shields.io/npm/v/dsh-rss-news-daily)](https://www.npmjs.com/package/dsh-rss-news-daily)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue)](LICENSE)

`dsh-rss-news-daily` 是一款运行在 dsh 中的新闻阅读与整理工具。你可以把常看的新闻网站订阅到一起，让插件定时收集更新；再用「全部新闻」随时浏览，或交给 AI 整理成每日精选和时段快报。

它适合希望持续关注行业动态、科技资讯或其他主题，又不想每天手动打开一堆网站的人。订阅哪些来源、关注什么内容、何时更新，都由你自己决定。

## 你可以用它做什么

### 每天快速了解重点

插件会定时检查你启用的新闻源，并根据新闻内容进行整理。打开「今日精选」，可以阅读当天的重点新闻和 AI 总结；「时段快报」则帮助你快速了解最近一段时间值得留意的动态。没有时间逐条阅读时，先看精选内容就能对当天新闻形成概览。

### 把常看的新闻放在一起

「全部新闻」汇集已抓取的订阅内容。你可以搜索标题和内容、按分类筛选、只看未读新闻，也可以按时间排序。点开新闻即可前往原始来源阅读；喜欢的来源和分类也可以按自己的习惯调整。

### 自由管理订阅来源

可以从插件提供的内置来源开始，也可以添加新闻网站提供的更新链接（RSS/Atom），或导入 OPML 订阅清单文件。来源可以启用、暂停、编辑或删除；不再需要的内置来源也可以恢复。导出 OPML 后，还能把自己的订阅清单带到其他阅读器中。

### 让精选更贴近你的兴趣

在新闻条目上表达喜欢或不感兴趣，插件会将这些反馈用于调整后续推荐。你也可以设置关注的分类、抓取时间和每日精选生成时间，让内容安排更符合自己的阅读节奏。

### 阅读外文新闻、查看任务进度

需要时可以使用 AI 翻译新闻。抓取和翻译时可以查看进度；如果任务还在进行，也可以取消。订阅源暂时无法访问时，可以查看来源状态并按需重试。

## 使用方式

1. 安装插件并打开独立的新闻面板。
2. 选择感兴趣的新闻分类，启用想关注的来源；也可以添加 RSS/Atom 更新链接或导入 OPML 订阅清单。
3. 按需设置自动抓取和每日精选的时间。默认设置也可以直接开始使用。
4. 平时在「今日精选」快速浏览重点，在「全部新闻」搜索和阅读新闻列表。

首次使用 AI 精选、总结或翻译前，请确保 dsh 已配置可用的 AI 模型。新闻内容由订阅源提供；能否查看原文全文取决于原始网站。

## 数据与隐私

- 插件使用独立的阅读面板，不会自动把新闻放进聊天对话。
- 新闻条目、订阅来源和阅读偏好保存在本机。
- 使用 AI 进行新闻评分、总结或翻译时，相关内容会发送给你在 dsh 中配置的模型服务；具体处理方式取决于所使用的模型服务。

## 安装

在 dsh 的插件管理中搜索 `dsh-rss-news-daily` 并安装。也可以使用命令行：

```bash
dsh plugin --profile web add dsh-rss-news-daily
```
